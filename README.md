# Krython Homelab - Self-hosted Datacenter

My home lab running on Proxmox VE 8.4

### 🖥️ Hardware
- **Server:** Xeon E5-2673 v3 / 32GB RDIMM
- **Hypervisor:** Proxmox VE 8.4

### 📦 Stack
- **OS:** Ubuntu, Debian, AlmaLinux (3 VMs)
- **Services:** Docker 29 + Portainer CE
- **Network:** WireGuard VPN, IPv6 DNS

### 🎯 What I learned
- Setting up Proxmox cluster from scratch
- Deploying Docker services via Portainer
- Configuring WireGuard VPN for remote access
- Fixing IPv6 DNS issues

Currently in progress - automating backups with Python.
